title: "Genie MCP Server: programmatic workspace access"
description: "Connect Claude Desktop, Cursor, or any MCP-compatible AI client to your Genie workspace. Create projects, send prompts, manage members, and query usage — all programmatically via OAuth 2.0."
---

The Genie MCP Server lets external AI clients — Claude Desktop, Cursor, custom agents — connect to your Genie workspace and manage it programmatically. Once connected, the AI can create projects from prompts, send follow-up instructions, browse build history, manage members, query credit usage, and more, all through the same tools the Genie web app uses.

<Note>
The Genie MCP Server is available on all paid Genie plans. Each connection is scoped to a single workspace via OAuth 2.0. Only the tools allowed by your role within that workspace are accessible.
</Note>

## Connect your client

### Endpoint

```
https://www.genie-app.de/api/mcp
```

The server uses the **Streamable HTTP** MCP transport (`POST`, `GET`, and `DELETE` on the same URL).

### Authentication

The Genie MCP Server uses **OAuth 2.0 with PKCE**. Each authorisation is scoped to a single workspace — you choose which workspace to authorise during the OAuth flow, and every tool call is restricted to that workspace.

Most MCP clients (Claude Desktop, Cursor) handle the OAuth flow automatically when you paste the endpoint URL into their settings and start a conversation. The client receives a short-lived token that Genie refreshes automatically.

### Example: Claude Desktop

Add the following entry to your `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "genie": {
      "url": "https://www.genie-app.de/api/mcp",
      "transport": "streamable-http"
    }
  }
}
```

Restart Claude Desktop and open any conversation. Claude will prompt you to authorise the Genie connection the first time a Genie tool is invoked.

## Available tools

The Genie MCP Server provides tools across eighteen categories.

### Workspace management

Read and update your workspace, members, invitations, settings, and billing.

| Tool | What it does |
|---|---|
| `get_workspace_info` | Name, member count, settings, and creation date |
| `list_workspace_members` | Members with roles and join dates |
| `list_workspace_invites` | Pending invite links with expiry and remaining uses |
| `invite_workspace_member` | Create a shareable invite link for a given role |
| `revoke_workspace_invite` | Cancel a pending invite |
| `update_workspace_member_role` | Change a member's role |
| `remove_workspace_member` | Remove a member immediately |
| `update_workspace` | Rename the workspace or update its description |
| `update_workspace_settings` | Toggle activity log or project access control |
| `get_workspace_billing` | Subscription plan, status, and billing period |
| `get_workspace_credits` | Current credit balance |
| `get_credit_usage` | Credit consumption, optionally broken down by project, member, or day, and sortable by spend or date |
| `get_recent_workspace_activity` | Activity log with filters and pagination |
| `list_workspaces` | All workspaces the authenticated user belongs to |
| `list_user_workspaces` | Same list, with the currently-connected workspace marked |
| `create_workspace` | Create a new workspace, owned by you. Independent of the currently connected workspace — it appears in your workspace list right away |
| `invite_workspace_member_by_email` | Send a single-use invite directly to an email address. The invitee doesn't need an existing Genie account — they become a member once they accept |

### Projects

Browse projects, create new ones from prompts, and manage the full project lifecycle.

| `get_project_status` | Lightweight check: is a build currently running? |
| `get_project_build_status` | The richest live-status call — phase, countdown ETA, progress, active agents, preview link, changed pages, closing summary, and suggested follow-ups, matching the web app's build-status card |
| `list_connected_project_activity` | What a project (or every project connected to a given workspace chat) is doing right now — building, running autofix, or has prompts waiting in its queue — the same snapshot the status badge on every workspace-chat surface shows. Pass a `conversation_id` and/or a `project_slug` |
| `list_project_viewers` | Who else has a project open right now — the same presence snapshot as the viewers badge on the project page. Never lists the caller themselves; an empty list means they're the only one there |
| `get_project_deployment_status` | Full phase-by-phase build breakdown |
| `get_project_deployment_plan` | Files the AI planned to create or modify |
| `get_project_messages` | Build history and chat turns |
| `show_preview` | Deployment URL and per-page screenshots |
| `get_project_screenshots` | Fetch actual screenshot images of a project — not just a URL — attached directly to the tool result: the deployed app's default view, and, when available, exactly what the connected user had open in their own live preview |
| `search_project_console_logs` | Search a deployed project's live runtime telemetry — console output, errors, unhandled crashes, clicks, and page views — filtered by keyword, severity, or event type, over a configurable time window |
| `suggest_project_prompts` | AI-generated next-step ideas based on build history |
| `abort_project_build` | Cancel the currently running build |
| `archive_project` / `unarchive_project` | Hide or restore a project |
| `list_archived_projects` | All archived projects in the workspace |
| `delete_project` | Permanently delete a project |
| `update_project` | Rename, update description, change visibility, or toggle remixing |
| `list_project_members` | Members explicitly granted access (when project access control is on) |
| `add_project_member` / `remove_project_member` | Grant or revoke a member's access to a specific project |
| `rename_project` | Rename a project (a focused alternative to `update_project`) |
| `add_project_to_workspace` | Move one of your personal projects into the connected workspace |
| `remove_project_from_workspace` | Remove a project from the workspace without deleting it — it becomes a personal project again |
| `get_project_deletion_status` | Check whether a project has a deletion in progress from the web app's Danger Zone, and whether it's still inside the cancellable grace window |
| `cancel_project_deletion` | Cancel an in-progress project deletion started from the web app, while still inside the grace window |
| `get_auto_mode_state` | Check whether [Auto mode](/projects/auto-mode) is running for a project: enabled flag, prompts used so far, and session limits |
| `set_auto_mode` | Turn Auto mode on or off for a project |
| `list_project_deployment_versions` | List a project's past deployed versions, newest first, so you can pick one to restore |
| `rollback_project_deployment` | Restore a project to a previous version's code and trigger a fresh deploy. Overwrites the project's current code — requires `confirm_rollback: true` |
| `get_project_seo_settings` | Read a project's current page title, meta description, canonical URL, Open Graph image, and noindex flag |
| `update_project_seo_settings` | Update a project's page title and/or meta description. Canonical URL, Open Graph image, and noindex stay read-only via MCP for now — set those from the web app's SEO settings tab |

### Project code graph

Ask questions about a project's own code — useful for an external AI client that needs to understand a project before changing it or answering questions about it.

| Tool | What it does |
|---|---|
| `query_project_code_graph` | Ask a natural-language question about a project's code — callers/callees, imports, symbol history, recent changes, or a free-text search — and get back file paths and exact line numbers |

### Project feature tree

Genie tracks every feature, area, and capability it builds into a project as a tree — visible in the project's **Brain** tab in the web app. These tools let an external AI client read and maintain that tree. Reading is available to anyone who can view the project; adding or editing a goal requires project ownership.

| Tool | What it does |
|---|---|
| `list_project_goals` | List the full feature tree — every tracked feature area, feature, and task, with its status (`todo`, `in_progress`, `implemented`, `failed`, `blocked`, `abandoned`) |
| `get_project_goal_details` | Deep-dive one feature: its status-change history, the code files that implement it, and (for a feature area) how much of it is done |
| `create_project_goal` | Add a feature to the tree to track it — this only records intent, it does not start a build |
| `update_project_goal` | Rename a feature, change its acceptance criteria, or update its status |
| `suggest_next_prompts` | Get ready-to-send prompt suggestions for what to build next, based on the project's open features |

### Bug tracking

Genie de-duplicates bugs across your projects: when the same class of bug shows up again, it reuses the fix that worked last time instead of investigating from scratch. These tools let an external AI client read and file into that system. Reading is available to anyone who can view the project; filing a bug requires project ownership.

| Tool | What it does |
|---|---|
| `get_known_issues` | List a project's tracked bug sightings — each one's source, status, a summary, and the cross-project bug pattern it was matched to (if any) |
| `report_known_issue` | File a bug into the knowledge base so it's de-duplicated against known patterns and its eventual fix can be reused across projects. Advisory tracking only — it never starts a build. Only the project owner can call this |
| `find_bug_solutions` | Search the shared bug-knowledge base for a proven fix by describing the symptom in natural language — across all Genie projects, not just this workspace's. Read-only, and not scoped to any project or workspace, since results are generalized and scrubbed of project-specific details |

### User memory

Genie's workspace AI remembers things you've mentioned about yourself in chat — your preferences, tools, team, goals — and brings that context into later conversations automatically. These tools let an external AI client search or delete that memory. Scoped to the connected user across all their workspaces, not to the currently connected workspace, since memory is a per-user concept.

| Tool | What it does |
|---|---|
| `search_user_memory` | Search everything Genie remembers about the connected user, ranked by relevance to a query, or list the most recently reinforced memories when no query is given. Read-only |
| `forget_user_memory` | Permanently delete one specific remembered fact about the connected user by id (obtained from `search_user_memory`) |

### Genie Cloud database

Browse the tables in a project's connected [Genie Cloud](/cloud/overview) database. Read-only. Only the project owner can use these tools, since table data may include the project's own end-users' data.

| Tool | What it does |
|---|---|
| `list_project_database_tables` | List a project's database tables and views, with column and approximate row counts |
| `get_project_database_table_preview` | Column definitions and up to 25 sample rows for one table |

Migration history isn't available via MCP. Ask the Genie workspace AI directly to review a project's migration history.
</Note>

### Project storage

Browse and manage the files in a project's Genie Cloud storage buckets. Only the project owner can use these tools.

| Tool | What it does |
|---|---|
| `list_project_storage_files` | List the files and folders in a storage bucket, optionally scoped to a subfolder |
| `create_project_storage_folder` | Create a folder in a storage bucket |
| `delete_project_storage_items` | Permanently delete one or more files or folders (deleting a folder deletes everything inside it) — requires `confirm_delete: true` |

</Note>

### Project Prompt Queue

When a follow-up prompt arrives for a project that's already building, Genie queues it instead of refusing it — see [Genie AI queues a busy project's prompt](/workspaces/overview#genie-ai-queues-a-busy-projects-prompt). These tools let an external AI client inspect and manage that queue directly.

| Tool | What it does |
|---|---|
| `list_prompt_queue` | Show a project's prompt queue: active/paused state (and why), pending items, when the next one goes out, and recent history |
| `pause_prompt_queue` | Pause the queue — nothing new is sent until resumed. Never stops a build already running |
| `resume_prompt_queue` | Resume a paused queue. Restarts the cooldown from now, so resuming never fires a burst |
| `remove_prompt_queue_item` | Cancel one still-waiting queued prompt |
| `reorder_prompt_queue_item` | Move a waiting prompt to a different position in the queue |
| `clear_prompt_queue` | Cancel every still-waiting prompt in a project's queue — requires `confirm_clear: true` |
| `set_prompt_queue_delay` | Change the cooldown between a run completing and the next queued prompt going out |
| `send_next_queued_prompt_now` | Skip the remaining wait and send the next queued prompt as soon as the project is free. Also resumes a paused queue |

### Workspace chat

Send questions to the Genie workspace AI and browse past conversations. Every tool here acts on any chat in the connected workspace, including one a teammate started, not just the caller's own — `list_workspace_chats`/`search_workspace_chats` default to the caller's own conversations, but accept a `scope: "workspace"` to include everyone's.

| Tool | What it does |
|---|---|
| `send_workspace_chat` | Ask a question about your workspace and get an AI response |
| `create_workspace_chat` | Start or continue a persistent chat thread (saved to chat history) |
| `list_workspace_chats` | Recent conversations with title and preview. Own conversations by default; pass `scope: "workspace"` to include teammates' |
| `get_workspace_chat` | Read a conversation's transcript by id, including a teammate's — windowed to the most recent 30 turns by default (up to 100), each turn capped at 2,000 characters. Check `truncated`/`totalMessages` before assuming you have the whole thing |
| `search_workspace_chats` | Search across past messages. Own conversations by default; pass `scope: "workspace"` to include teammates' |
| `search_agent_run_traces` | Fulltext-search the execution trace behind the connected user's own Genie AI conversations — the reasoning, every tool call, and the final answer, not just the visible chat text. Useful for questions like "why did that fail earlier" or "which turn called the deploy tool" |
| `rename_workspace_chat` | Rename any conversation in the workspace, including one a teammate started |
| `delete_workspace_chat` | Permanently delete any conversation in the workspace, including one a teammate started, and all its messages. Irreversible — check the conversation's `startedByUser` field first if you didn't start it yourself |
| `get_project_chat_connection` | Show which workspace chat is a project's main conversation — the one where all the work on that project happens — how that was resolved, and which other projects share it |
| `list_projects_sharing_chat` | List every project that uses a given workspace chat as its main conversation |
| `connect_project_chat` | Make a workspace chat a project's main conversation. Keeps an existing connection by default — pass `replace: true` to switch it |

| Tool | What it does |

| `list_design_mocks` | List a project's mock-up sessions, to pick a conversation back up |
| `get_design_mock_round` | Re-fetch an earlier round's images |

| `brief_design_mock_for_build` | Turn an approved mock-up's change list into a build brief for `send_followup_prompt` |

## Quick examples

### Create a project and follow up

```
Tool: create_project
{ "prompt": "A SaaS dashboard with auth, dark mode, and a billing page" }

→ Returns: deploymentUrl, slug

Tool: send_followup_prompt
{ "project_slug": "my-app-abc123", "prompt": "Add a CSV export button to the reports page" }
```

The `create_project` call starts the build immediately and returns the deployment URL. Use `get_project_build_status` to poll for everything at once — phase, ETA, progress, and the closing summary once it's done — or `get_project_status` for a lightweight running/not-running check.

### Roll back to a previous version

```
Tool: list_project_deployment_versions
{ "project_slug": "my-app-abc123" }

→ Returns: version ids, newest first

Tool: rollback_project_deployment
{ "project_slug": "my-app-abc123", "version": "42", "confirm_rollback": true }
```

Omit `version` to roll back to the most recent previous version. The rollback runs in the background — poll `get_project_deployment_status` for progress.

### Check credit usage this month

```
Tool: get_credit_usage
{ "range": "30d", "group_by": "project" }

→ Returns: { totalCredits: 142, byProject: [...] }
```

Admins can pass `scope: "workspace"` to see total consumption across all members. Members can only query their own usage. Add `"sort": "credits_desc"` (or `credits_asc`) to sort the breakdown by spend, highest first — or `date_desc`/`date_asc` when grouping by day.

### Ask a question about a project's code

```
Tool: query_project_code_graph
{ "project_slug": "my-app-abc123", "question": "who calls createCheckoutSession" }

→ Returns: matching symbols with file paths and exact line spans
```

### Invite a new team member

```
Tool: invite_workspace_member
{ "role": "member", "max_uses": 1, "expires_in_days": 7 }

→ Returns: { inviteUrl: "https://www.genie-app.de/workspace/invite/abc123", role: "member" }
```

## Permissions

Role-based access is enforced on every tool call.

| Action | Required role |
|---|---|
| Read workspace info, members, projects, chat | Any member |
| Read workspace-wide credit usage | Owner or admin |
| Invite or remove members, change roles | Owner or admin |
| Update workspace name or settings | Owner or admin |
| Manage MCP integrations | Owner or admin |
| Manage PII rules | Owner or admin |
| Create, update, rename, archive, or delete projects | Any member |
| Move a project in or out of the workspace | Owner, admin, or member (not editor) |
| Check or cancel a scheduled project deletion | Project owner |
| Send follow-up prompts and trigger builds | Any member |
| Turn Auto mode on or off for a project | Any member |
| Query a project's code graph | Any member |
| Read a project's feature tree | Any member (who can view the project) |
| Add or edit a feature in the tree | Project owner |
| Read a project's known issues | Any member (who can view the project) |
| Report a known issue | Project owner |
| Search the shared bug-solution knowledge base | Any connected user |
| Search or forget the connected user's memory | Any connected user |
| Search the connected user's own Genie AI run traces | Any connected user |
| View a project's screenshots or search its live console logs | Any member (who can view the project) |
| Read or set a project's main workspace chat | Any member |
| Read, rename, or delete a workspace chat (own or a teammate's) | Any member |
| Check what a project is doing right now (build, autofix, queue) | Any member (who can view the project) |
| See who else has a project open right now | Any member (who can view the project) |
| View or manage a project's prompt queue | Any member |
| Generate, view, or give feedback on a project's design mock-ups | Any member |
| Roll back a project or view its version history | Project owner |
| Read or update a project's SEO settings | Project owner |
| Browse a project's Genie Cloud database tables | Project owner |
| List a project's deployed edge functions | Project owner |
| Manage a project's scheduled jobs | Project owner |
| Manage a project's Genie Cloud roles, sign-in providers, and access settings | Project owner |
| Manage a project's secrets | Project owner |
| Manage a project's storage files | Project owner |
| Read Genie pricing | Any member |
| Read Genie's status page | Any connected user |
