<Update label="June 17, 2026" description="Weekly release">

A packed week with improvements to the building experience, Genie Cloud, and the chat interface.

## New features

- **"Pages I updated" after every build.** After Genie finishes a build, the response now shows a row of buttons — one for each page that was touched. Click any button to navigate your live app preview directly to that page, without having to search for what changed.

- **App onboarding flows and private mode.** Configure a first-login onboarding experience for your app's users and restrict access with private mode — without writing any code. Enable both from the **Onboarding** tab in project settings, or ask Genie AI in workspace chat to turn them on, invite users, or approve pending signups. See [App onboarding and access control](/cloud/onboarding).

- **Asset uploads via drag and drop.** Drag images or videos directly into the project chat prompt to include them in your app (hero images, logos, product photos). You can also upload assets to any project from the command palette (**Cmd/Ctrl+K → "Upload images & videos"**) without triggering a full build.

- **File uploads with a real progress bar.** When you ask Genie to add a file upload feature with a visible progress bar, the generated code now uses a genuine upload progress indicator tied to actual transfer progress — not a timer animation.

## Updates

- **Smarter, honest build ETA.** The build time estimate now adjusts in real time based on the observed pace. If a step takes longer than expected, the estimate revises upward instead of expiring into a static "taking longer than expected" message. A rising ETA is more useful than one that freezes.

- **Browser tab shows build status.** When you switch to another tab while Genie is building, the project tab now shows ⏳ while work is in progress and ✅ once it finishes. Switching back to the tab clears the badge automatically.

- **"Continue with Genie AI" in chat mode.** When Genie answers a follow-up question without building (chat mode), a **Continue with Genie AI** button appears below the answer. Clicking it opens workspace chat pre-loaded with your question and Genie's answer so you can keep the conversation going with full context.

- **Richer schema evolution.** Genie can now change a column's data type (for example, converting a text column to a proper date field) and set or remove column defaults on existing tables — no longer limited to adding new columns. Your existing data is preserved. See [Database](/cloud/database).

- **More reliable delete and update operations.** Generated app code now verifies that a delete or update actually changed a row in the database. If the operation was silently blocked, the app shows the user an error message instead of falsely reporting success.

- **Email works for any use case.** Asking Genie to send any outbound email — booking confirmations, order receipts, password-reset links, welcome messages, reminders — now reliably triggers the email integration. Previously, only requests that explicitly mentioned "transactional email" or the provider name were guaranteed to pick it up.

- **Multi-role apps tell you what to do next.** When Genie builds an app with distinct user roles (admin, contractor, client, and so on), it now lists the exact role names in the build summary and adds an actionable checklist item reminding you to assign those roles to your users in **Project Settings → Users**, or to ask Genie AI to handle it.

</Update>

<Update label="May 20, 2026" description="Weekly release">

This week brings the first wave of public-facing improvements across projects, Genie Cloud, workspaces, and billing.

## New features

- **Genie Cloud is now generally available.** Every app you build can opt into a managed backend with a database, file storage, user authentication, and edge functions — set up automatically with no configuration. See [Genie Cloud overview](/cloud/overview).
- **Import a Claude design as a starting point.** Drop in an HTML file exported from a Claude design and Genie turns it into a working project you can refine with follow-up prompts. See [Import a design](/projects/import-design).
- **Workspace MCP integrations.** Connect Linear, GitHub, Notion, Stripe, and more to your workspace through MCP — one shared connection is available to every member and every project. See [Workspace integrations](/workspaces/integrations).
- **Project secrets.** Store API keys and other sensitive values securely at the project level. Your running app reads them automatically and they are never exposed in code or chat. See [Project secrets](/projects/secrets).
- **Templates gallery.** Start from a ready-made portfolio, dashboard, CRM, tracker, and more, then customize with follow-up prompts. See [Templates](/templates).

## Updates

- **New plans: Starter, Genie, Teams, and Enterprise.** Every plan now includes the same features — pick one based on credits, custom domain, and team workspace needs. See [Plans](/billing/plans).
- **Top-ups for paid plans.** Buy additional credits on demand. Top-ups stack on top of your monthly allowance and never expire. See [Top-ups](/billing/topups).
- **Clearer credit usage.** Credits now show how they're counted, per-plan limits, what happens when you run out, and how to check your balance. See [Credits](/billing/credits).
- **Publishing and sharing controls.** Choose who can access your project, grab a shareable link, allow remixing, and connect a custom domain to your live app. See [Publish and share](/projects/visibility).
- **Workspace member management.** Invite teammates by link or email, assign roles, change roles later, and remove members when needed. See [Members](/workspaces/members).
- **Anonymous users in Genie Cloud Auth.** Review registered users and understand how sign-in, sign-up, and anonymous sessions work. See [Authentication](/cloud/auth).
- **Automatic database management.** Genie creates and updates your app's tables automatically. Inspect tables and data from the Cloud tab. See [Database](/cloud/database).
- **Public and private storage buckets.** Genie Cloud organizes file storage into buckets so you can choose what's shared and what stays private. See [Storage](/cloud/storage).
- **German-language documentation.** The full docs are now available in German for all of the above.
- **Customer compliance package (DE).** German customers can request the AVV, TOM, sub-processor list, deletion concept, and data-subject-rights processes in one bundle. See [Compliance-Paket](/de/compliance/kunden-compliance-paket).

</Update>
