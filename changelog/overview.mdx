<Update label="June 14, 2026" description="Weekly release">

This week brings multi-role apps, app onboarding flows, private mode for apps, AI-powered "What's next" suggestions, and a handful of quality-of-life improvements.

## New features

- **Multi-role apps — roles created automatically and named in your summary.** When you build an app with multiple access tiers (admin, contractor, client, and similar), Genie now creates each custom role automatically and lists the exact role names in the build summary. You can then assign those roles to your users straight from **Project Settings → Users** without guessing what to type. See [User roles and access control](/cloud/auth#user-roles-and-access-control).

- **App user onboarding flows.** Ask Genie to add a first-login onboarding screen to your app, or toggle it on from **Project Settings → Onboarding**. New users are held on a guided page after signing up until they complete it — collecting a display name and any custom fields you configure. The flow runs exactly once per user and is tracked in your Genie Cloud database.

- **Private mode for apps.** Enable private mode to require admin approval before a new sign-up can access your app. Unauthenticated visitors see a locked page; new sign-ups wait for approval. Approve individual users from **Project Settings → Users**, or ask Genie in the workspace chat to approve them or send pre-approved invites by email. Enable from **Project Settings → Onboarding**. See [User authentication](/cloud/auth#user-roles-and-access-control).

- **"Ask Genie AI" on the post-build checklist.** After a build, the to-do checklist now has an **Ask Genie AI** button. Clicking it opens a chat pre-filled with a prompt based on your remaining unchecked tasks — no retyping required.

- **"What's next" — AI suggestions in the Brain panel.** After each build, Genie predicts the features, changes, or fixes you are most likely to want next and shows them as clickable cards in the **Brain** panel. Clicking a card pre-fills the prompt with ready-to-send text; you stay in full control of what gets built.

- **Build completion sound.** A soft two-note chime now plays when a build finishes, so you know your result is ready without watching the screen.

## Updates

- **Build progress shows each phase.** The loading indicator during a build now lists every phase in order — optimizing your prompt, coding, deploying, saving summary — with a live elapsed timer on the active phase and a checkmark on each completed one.

- **Project list refreshes automatically.** The project grid on your home page and workspace home now updates every 60 seconds in the background and whenever you return to the tab. Previously the list could show stale data until you hard-refreshed the page.

- **Autofix responses in your language.** When Genie automatically fixes a broken page or runtime error, the status message now appears in your browser's language instead of always in English.

</Update>

<Update label="May 20, 2026" description="Weekly release">

This week brings the first wave of public-facing improvements across projects, Genie Cloud, workspaces, and billing.

## New features

- **Genie Cloud is now generally available.** Every app you build can opt into a managed backend with a database, file storage, user authentication, and edge functions — set up automatically with no configuration. See [Genie Cloud overview](/cloud/overview).
- **Import a Claude design as a starting point.** Drop in an HTML file exported from a Claude design and Genie turns it into a working project you can refine with follow-up prompts. See [Import a design](/projects/import-design).
- **Workspace MCP integrations.** Connect Linear, GitHub, Notion, Stripe, and more to your workspace through MCP — one shared connection is available to every member and every project. See [Workspace integrations](/workspaces/integrations).
- **Project secrets.** Store API keys and other sensitive values securely at the project level. Your running app reads them automatically and they are never exposed in code or chat. See [Project secrets](/projects/secrets).
- **Templates gallery.** Start from a ready-made portfolio, dashboard, CRM, tracker, and more, then customize with follow-up prompts. See [Templates](/templates).

## Updates

- **New plans: Starter, Genie, Teams, and Enterprise.** Every plan now includes the same features — pick one based on credits, custom domain, and team workspace needs. See [Plans](/billing/plans).
- **Top-ups for paid plans.** Buy additional credits on demand. Top-ups stack on top of your monthly allowance and never expire. See [Top-ups](/billing/topups).
- **Clearer credit usage.** Credits now show how they're counted, per-plan limits, what happens when you run out, and how to check your balance. See [Credits](/billing/credits).
- **Publishing and sharing controls.** Choose who can access your project, grab a shareable link, allow remixing, and connect a custom domain to your live app. See [Publish and share](/projects/visibility).
- **Workspace member management.** Invite teammates by link or email, assign roles, change roles later, and remove members when needed. See [Members](/workspaces/members).
- **Anonymous users in Genie Cloud Auth.** Review registered users and understand how sign-in, sign-up, and anonymous sessions work. See [Authentication](/cloud/auth).
- **Automatic database management.** Genie creates and updates your app's tables automatically. Inspect tables and data from the Cloud tab. See [Database](/cloud/database).
- **Public and private storage buckets.** Genie Cloud organizes file storage into buckets so you can choose what's shared and what stays private. See [Storage](/cloud/storage).
- **German-language documentation.** The full docs are now available in German for all of the above.
- **Customer compliance package (DE).** German customers can request the AVV, TOM, sub-processor list, deletion concept, and data-subject-rights processes in one bundle. See [Compliance-Paket](/de/compliance/kunden-compliance-paket).

</Update>
