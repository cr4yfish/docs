Die meisten Projekte, die du in Genie baust, haben eine Oberfläche — Seiten, die jemand öffnet und durchklickt. Ein **Genie Agent** ist anders: Er ist eine kleine Backend-Automatisierung ohne eigene Oberfläche. Du gibst ihm eine typisierte Eingabe, er durchläuft eine kurze Abfolge von Schritten und liefert eine typisierte Ausgabe zurück. Denk an: „Wenn dieser Webhook auslöst, schau in der Datenbank nach, lass die KI eine Antwort entwerfen und poste sie irgendwo" — ganz ohne einen eigenen Server dafür zu betreiben.

<Note>
  Genie Agents gehören zu deinem **Workspace**, nicht zu einem einzelnen Projekt — ein Agent kann aber an eines deiner Projekte gebunden werden, wenn er dessen eigene Datenbank oder eigenen Backend-Code braucht. Siehe [Workspaces-Übersicht](/de/workspaces/overview). In der URL und an ein paar entwicklerseitigen Stellen heißen sie weiterhin „Workflows" — dasselbe Feature, dieselben Daten, nur der eine Name, den eine Person liest, und der andere, den ein Link verwendet.
</Note>

## Was ein Genie Agent ist

Ein Genie Agent ist eine kurze Abfolge von **Schritten**. Jeder Schritt erledigt eine Sache, und ein späterer Schritt kann das Ergebnis eines früheren nutzen — zum Beispiel kann der KI-Schritt die E-Mail-Adresse verwenden, die der Datenbank-Schritt gerade nachgeschlagen hat. Das musst du nicht selbst verdrahten: Genie ermittelt die Reihenfolge automatisch aus dem, was du eingibst.

Aktuell stehen sechzehn Arten von Schritten zur Verfügung:

| Schritt | Was er tut |
|---|---|
| **Datenbank** | Führt eine Abfrage gegen eine Genie-Cloud-Datenbank aus — standardmäßig das an den Agenten gebundene Projekt, oder jede andere Genie App in deinem Workspace |
| **Workspace-Tabelle** | Liest oder schreibt Zeilen in einer der eigenen Tabellen deines Workspace — kein Genie-Cloud-Projekt nötig. Dieselben Tabellen, die ein [Genie Tool](/de/workspaces/genie-tools) anzeigen kann |
| **HTTP** | Ruft eine externe URL auf — sendet einen Webhook, spricht eine externe API an |
| **KI** | Bittet Genies KI, als ein Schritt im Ablauf etwas zu erledigen — zusammenfassen, einen Text entwerfen, eine Entscheidung treffen |
| **Edge Function** | Führt eine bereitgestellte Backend-Funktion aus — standardmäßig die des an den Agenten gebundenen Projekts, oder die jeder anderen Genie App in deinem Workspace |
| **Verbundene App** | Ruft ein Tool einer der [verbundenen Integrationen](/de/workspaces/integrations) deines Workspaces auf — Linear, Notion, Outlook und mehr — oder **Genie selbst**, immer verfügbar als integrierte verbundene App, ganz ohne Einrichtung |
| **Benachrichtigung** | Sendet eine Benachrichtigung in die Genie-App, an die Person, die den Agenten ausgeführt hat, an den Eigentümer bzw. die Eigentümerin des Agenten oder an den Eigentümer und die [Follower](#benachrichtigungen-eines-agenten-erhalten) des Agenten. Die Ausgabe enthält Titel und Nachricht, die gesendet wurden — ein Agent, dessen ganze Aufgabe die Benachrichtigung ist, kann also zurückgeben, was er gesagt hat |
| **Websuche** | Durchsucht das lebende Web. **Schnell** liefert die Ergebnisse als Daten zurück — Titel, Links, Ausschnitte — für einen späteren Schritt; **Tief** recherchiert eine Frage in einer Schleife und liefert einen Bericht mit Quellenangaben, ein Schritt, der Minuten dauert und Credits verbraucht. Ein Zeitlimit (bis zu 20 Minuten) begrenzt eine tiefe Suche, und beim Erreichen bleibt erhalten, was gefunden wurde |
| **Webseite lesen** | Liest eine Seite über Genies sicheren Seitenleser (denselben, den Genie AI im Chat verwendet) und liefert ihren Text zurück |
| **Compliance-Prüfung** | Prüft einen Wert gegen die [PII-Regeln](/de/workspaces/pii-rules) und/oder [Guardrails](/de/workspaces/guardrails) deines Workspace, bevor er im Ablauf weitergeht |
| **Genie Tool** | Nutzt eine Seite eines [Genie Tools](/workspaces/genie-tools) in deinem Workspace — öffnet sie, drückt eine Schaltfläche oder sendet ihr Formular ab oder liest ein Raster — und liefert zurück, was sie gezeigt oder getan hat. Der Schritt läuft als die Person, die den Agenten gestartet hat, und erreicht daher nur Tools und Daten, die sie nutzen darf. Bei einem Agenten, der als ein bestimmtes Mitglied läuft, wird ein Genie-Tool-Schritt abgelehnt, wenn jemand anderes ihn gestartet hat |
| **Ein anderer Agent** | Ruft einen Genie Agent auf, den du bereits gebaut hast, sodass du kleinere Abläufe zu größeren zusammensetzen kannst |
| **Wenn / sonst** | Verzweigt den Ablauf — prüft frühere Ergebnisse mit UND / ODER / NICHT und führt je nachdem unterschiedliche Schritte aus. Siehe [Verzweigen](#verzweigen) |
| **Knowledge** | Durchsucht, listet, liest, legt ab, aktualisiert oder löscht Dokumente in der [Wissensdatenbank](/de/workspaces/overview#wissensdatenbank) deines Workspace |
| **Ontology** | Durchsucht, liest oder ändert das [Wissensmodell](/de/workspaces/overview#wissensmodell) deines Workspace — Entitäten, Beziehungen und Klassen |
| **Schleife** | Wiederholt eine Reihe von Schritten über eine Liste, eine feste Anzahl von Malen oder solange eine Bedingung gilt. Siehe [Schleifen](#schleifen) |
| **Variable** | Hält einen benannten Wert — eine laufende Summe, einen Zähler — über die Durchläufe einer Schleife hinweg. Siehe [Schleifen](#schleifen) |

<Tip>
Ein **Datenbank**- oder **Edge-Function**-Schritt muss nicht beim an den Agenten gebundenen Projekt bleiben — richte ihn stattdessen auf jede andere Genie App in deinem Workspace aus, um deren eigene Datenbank zu lesen oder zu beschreiben oder ihre eigenen Backend-Funktionen aufzurufen. Wähle das Zielprojekt über die Auswahl des Feldes im Editor, oder sag Genie AI einfach, welche App du meinst.
</Tip>

<Tip>
Ein **Websuche**-Schritt auf **Schnell** liefert die rohen Ergebnisse, keine geschriebene Zusammenfassung — füge danach einen **KI**-Schritt hinzu, wenn Genie das Gefundene zusammenfassen oder darauf reagieren soll. So verbraucht eine geplante Suche nicht heimlich KI-Credits für eine Zusammenfassung, die niemand angefragt hat.
</Tip>

<Tip>
  Genie als integrierte verbundene App bedeutet, dass ein Schritt alles tun kann, was Genie AI selbst im Chat kann — ein Projekt erstellen, einen Folge-Prompt senden, eine Workspace-Einstellung ändern — als Teil einer Automatisierung, ohne Zugangsdaten einzurichten. Ein Schritt kann nur erreichen, was das Mitglied, dem der Agent gehört, auch durch eine direkte Anfrage an Genie AI erreichen könnte.
</Tip>

<Tip>
  Brauchst du etwas, das diese allein nicht abdecken? Greif zu einem Edge-Function-Schritt — er führt echten Code aus und kann daher alles, was eine individuelle Backend-Funktion kann.
</Tip>

## Zwei Wege, einen zu starten

<Steps>
  <Step title="Direkt auf der Seite erstellen">
    Öffne **Workspace → Genie Agents** und klicke auf **Neuer Agent**. Gib ihm einen Namen, eine kurze Beschreibung, wofür er da ist, und seinen ersten Schritt — das reicht, um dich direkt in den visuellen Editor zu bringen, wo du den Rest baust. Kein Gespräch mit Genie AI nötig, um loszulegen.
  </Step>
  <Step title="Oder Genie AI beschreiben">
    Sag der Workspace-KI, was du möchtest — genauso, wie du alles andere in Genie anfragst:

    - „Wenn eine neue Zeile in meiner Tabelle `orders` erscheint, schau die E-Mail-Adresse der Kundin oder des Kunden nach und sende ihr oder ihm eine Dankesnachricht"
    - „Prüfe jede Stunde meine Tabelle `signups` auf Neues und poste eine Zusammenfassung an meinen Slack-Webhook"
    - „Füge einen Schritt hinzu, der eine Antwort mit KI entwirft, bevor der Webhook gesendet wird"

    Genie AI baut und bearbeitet die Schrittfolge für dich und kann zuerst eine **Vorschau** ausführen — einen Testlauf, der zeigt, was jeder Schritt tun würde, ganz ohne echte Nebeneffekte: keine wirklich versendete E-Mail, keine wirklich gesendete Anfrage, keine wirklich ausgeführte Abfrage. Nutze sie (oder lass Genie sie nutzen), um einen neuen oder geänderten Agenten zu prüfen, bevor du ihn endgültig speicherst.
  </Step>
</Steps>

<Tip>
Wenn Genie AI einen Agenten für dich baut, zeigt der Chat eine kleine Pille mit dem Namen des Agenten — schimmernd, während er gebaut wird, mit einem Häkchen, sobald es ihn gibt. Drück darauf, um den Agenten zu öffnen: auf dem Desktop auf der Canvas neben dem Chat, wo seine Schritte entstehen, während Genie sie schreibt, auf kleineren Bildschirmen im Editor. Eine gelbe Pille heißt, dass nichts erstellt wurde, und ein Druck darauf zeigt, warum. Jeder Schritt, den Genie AIs Tools beim Arbeiten an einem Agenten ausführen, zeigt im Gesprächsverlauf ein Label in einfacher Sprache statt eines generischen „Arbeite daran".
</Tip>

**Ein Agent auf der Canvas liest sich von oben nach unten, das Ergebnis zuerst.** Seine Karte hat drei Abschnitte — **Ergebnis**, **Verlauf** und **Ablauf** — in einfachen Worten für alle, die nie einen Workflow-Editor gesehen haben: eine Zeile pro Schritt mit Symbol und schlichtem Namen (*Sucht passende Zeilen in Bestellungen* statt einer internen ID), ohne Verdrahtung oder Pfade. Eine Schleife und die Schritte, die sie wiederholt, stehen zusammen unter *Wiederholt 3 Schritte* (während eines Laufs *Durchgang 2 von 8*), und Zweige, die wieder zusammenlaufen, sind unter dem Schritt gruppiert, zu dem sie führen. Ein Agent, der noch nicht gelaufen ist, sagt das — einen Lauf startest du weiter im Chat. Während Genie AI den Agenten bearbeitet, ist jeder Schritt, den sie schreibt, an seiner Stelle als **Neu** oder **Ändert sich** markiert, live während die Änderung hereinkommt. Was jeder Abschnitt zeigt, steht unter [Lauf-Ergebnisse](#lauf-ergebnisse).

## Der visuelle Editor

Wähle einen Agenten auf der Seite **Genie Agents** aus, um zu seinem Editor zu gelangen — eine Arbeitsfläche, die jeden Schritt und seine Verbindungen zeigt. Die Karte eines Schritts ist eine Zeile: das Symbol seiner Art und sein Name; fahr über eine Karte oder wähle sie aus, um zu sehen, was der Schritt tut. Die erste Karte ist nach dem benannt, was den Agenten startet, und trägt den **Testlauf** als runde Play-Schaltfläche. Namen auf den Verbindungen erscheinen, wenn du darüberfährst, sie fokussierst oder auswählst. Auf dem Desktop zoomst du mit dem Mausrad, einer Pinch-Geste oder den Tasten **+**, **−** und **0**, und **Einpassen** zeigt alles; auf dem Handy bleiben die Zoom-Schaltflächen. Du kannst zwei Schritte verbinden, indem du auf die Ausgabe des einen und dann auf den Schritt klickst, der sie nutzen soll, einen Schritt umbenennen oder entfernen.

Speichern überschreibt nie eine neuere Version. Hat Genie AI, ein Zurücksetzen oder ein anderer Tab gespeichert, während du bearbeitet hast, bleibt dein Entwurf auf dem Bildschirm und der Editor bietet an, die neuere Version zu laden.

Um das Ergebnis eines früheren Schritts in einem Feld zu verwenden — einem KI-Prompt, einer Datenbankabfrage, einer URL — klicke auf das **+** neben der Feldbeschriftung. Eine verschachtelte Auswahl lässt dich in einen Schritt eintauchen und genau den Wert wählen, den du brauchst; er erscheint dann als Chip direkt im Feld, an der Stelle, an der du ihn platziert hast. Klicke auf einen Chip, um ihn gegen einen anderen Wert zu tauschen, oder wähle **Selbst schreiben**, um den Rohtext direkt zu bearbeiten.

<Tip>
  Im Hintergrund gibt es immer nur einen Agenten, nicht zwei konkurrierende Kopien. Was auch immer du auf der Arbeitsfläche änderst, sieht Genie AI beim nächsten Gespräch mit dir — und was Genie AI ändert, zeigt die Arbeitsfläche beim nächsten Öffnen.
</Tip>

**Einen Schritt finden.** Drücke auf einer großen Arbeitsfläche **⌘K** (Strg+K) oder **/** außerhalb eines Textfelds, um die Schritte nach Namen zu durchsuchen. Wähle einen aus, und die Arbeitsfläche gleitet zu ihm und öffnet sein Panel. Die Suchschaltfläche in der Werkzeugleiste der Arbeitsfläche öffnet dieselbe Suche auf dem Smartphone.

**Rahmen.** Fasse Schritte unter einem Namen zusammen, damit eine volle Arbeitsfläche lesbar bleibt. Wähle im Panel eines Schritts unter **Gezeichnet in** die Option **einen neuen Rahmen** oder verschiebe den Schritt in einen vorhandenen. Ein Rahmen lässt sich zu einer einzelnen Karte einklappen, umbenennen, an seinem Reiter verschieben oder auflösen. Rahmen ändern nur, wie die Arbeitsfläche aussieht, nie, wie der Agent läuft. Während eines Laufs zeigt ein eingeklappter Rahmen seinen aussagekräftigsten Status, sodass ein Fehler darin nie verborgen bleibt.

## Verzweigen

Ein **Wenn/sonst**-Schritt prüft eine oder mehrere Regeln gegen frühere Ergebnisse und kommt auf **ja (dann)** oder **nein (sonst)** — verknüpfe seine Regeln mit **UND** (alle müssen zutreffen), **ODER** (mindestens eine) oder **NICHT** (keine darf zutreffen). Zieh vom **Dann**- oder **Sonst**-Punkt des Schritts auf einen anderen Schritt, um ihn an diesen Zweig zu binden, oder wähle den Zweig stattdessen direkt unter **Läuft** in den Einstellungen dieses Schritts.

Ein Schritt, dessen Zweig nicht genommen wurde, wird übersprungen, nicht als fehlgeschlagen gewertet — sein Ergebnis zeigt **Zweig nicht genommen**. Ein Schritt an der Stelle, an der beide Zweige wieder zusammenlaufen (einer, der selbst keinen Zweig trägt), läuft unabhängig davon, welche Seite tatsächlich lief.

<Tip>
Bitte Genie AI, die Verzweigung für dich einzurichten — z. B. „schick die Benachrichtigung nur, wenn die Zeilenzahl über null liegt" — und sie richtet den Wenn/sonst-Schritt und die Bindung gemeinsam ein.
</Tip>

## Schleifen

Ein **Schleife**-Schritt wiederholt die darin enthaltenen Schritte, in einer von drei Formen: **für jedes** Element einer Liste (etwa die Zeilen einer Datenbank-Abfrage), eine **feste Anzahl von Malen**, oder **solange** eine Bedingung gilt. Ein **Variable**-Schritt hält einen benannten Wert über die Durchläufe hinweg — eine laufende Summe, einen Zähler, eine gesammelte Liste —, mit sechs Möglichkeiten, ihn bei jedem Durchlauf zu ändern: setzen, addieren, subtrahieren, multiplizieren, dividieren oder anhängen. Zusammen reicht das für Dinge, die eine feste Schrittfolge nicht kann, etwa „addiere jede Bestellung über 100 €" oder „prüfe wiederholt, bis der Build fertig ist."

Der Editor markiert die eigenen Schritte einer Schleife mit einem farbigen Punkt auf der Arbeitsfläche, sodass auf einen Blick klar ist, welche Schritte einmal und welche bei jedem Durchlauf laufen.

Ein Lauf macht insgesamt höchstens 500 Schritte, jeden Durchlauf mitgezählt. Eine Schleife, deren Durchläufe nicht in den Rest passen, schlägt vor dem ersten Durchlauf fehl und sagt das, statt auf halbem Weg zu stoppen. Eine Schleife mit Stopp-Regeln kann früher enden und schlägt deshalb nur fehl, wenn sie dieses Limit erreicht, während ihre Regeln noch gelten.

<Tip>
Bitte Genie AI zum Beispiel *„geh jede Zeile durch und addiere die Summe"* — sie richtet den Schleife- und den Variable-Schritt gemeinsam ein, genau wie bei jeder anderen Automatisierung.
</Tip>

## Einen Agenten testen

Bevor du eine Änderung endgültig machst, kannst du einen echten Test ausführen, um genau zu sehen, was ein Agent — oder nur ein Schritt davon — tatsächlich tut.

- **Testlauf** — die Play-Schaltfläche auf der ersten Karte startet einen echten Lauf deiner zuletzt gespeicherten Version und zeigt auf jeder Schrittkarte den Live-Status an, während er läuft: wartend, laufend, fertig oder fehlgeschlagen, zusammen mit dem Ergebnis jedes Schritts. Das verwendet deine echten Daten und verbundenen Apps und verbraucht die Credits, die es normalerweise verbrauchen würde — keine Simulation. Speichere deine Änderungen zuerst; ein Testlauf verwendet immer die gespeicherte Version.
- **Diesen Schritt testen** — testet einen einzelnen **Verbundene-App**-Schritt für sich allein, ohne zu speichern oder den Rest des Ablaufs auszuführen. Genie füllt realistische Beispielwerte für alles ein, was der Schritt normalerweise von einem früheren Schritt bekäme, sodass der Test wahrscheinlich beim ersten Versuch gelingt. Da es ein echter Aufruf ist, schreibt ein schreibender Schritt tatsächlich Daten.
- **Genie AI bitten, es zu beheben** — schlägt der Test eines Schritts fehl, gib den Fehler mit einem Klick an Genie AI weiter. Genie sieht das fehlgeschlagene Tool, die eigene Fehlermeldung der verbundenen App und genau das, was gesendet wurde, und schlägt eine Lösung vor.

<Tip>
  Genie AI kann auch in deinem Auftrag einen Schritt testen — bitte sie einfach darum, während du im Chat Änderungen an deinem Agenten beschreibst.
</Tip>

**Mit denselben Daten erneut ausführen.** Ist ein Lauf beendet, wiederholt **Mit denselben Daten erneut ausführen** ihn mit derselben Eingabe. Schritte, die nur lesen — etwa ein KI-, Websuche- (schnell oder tief) oder Knowledge-Schritt —, übernehmen, was der frühere Lauf gefunden hat, statt erneut zu laufen. So wartet der Wiederholungsversuch des einen fehlgeschlagenen Schritts oder ein Test einer Benachrichtigung nicht ein zweites Mal auf die vorgelagerte Recherche (und bezahlt sie auch nicht). Schritte, die schreiben oder senden — eine Benachrichtigung, ein Einfügen von Zeilen, eine Aktion einer verbundenen App —, laufen immer erneut, ebenso jeder Schritt, den du seitdem bearbeitet hast. Genie AI kann einen Lauf auch für dich erneut ausführen.

## Lauf-Ergebnisse

**Ein Lauf öffnet sich auf der Canvas seines Agenten.** Jeder Link zu einem Lauf — eine Benachrichtigung, Genie AI, eine Laufzeile in der Agentenliste — öffnet den Editor des Agenten und spielt diesen Lauf auf seinem Graphen ab: Jeder Schritt zeigt, wie er lief, was er ergab und einen etwaigen Fehler. Öffnest du einen Lauf, der noch läuft, folgt die Ansicht ihm. Ein Lauf eines anderen Agenten, einer, den es nicht mehr gibt, oder einer, den du nicht öffnen darfst, sagt das; schlägt das Lesen fehl, gibt es einen Neuversuch. Alte Links zur Seite eines Laufs oder zur **Läufe**-Seite eines Agenten funktionieren weiter und landen auf der Canvas.

Die eigene Ergebnisseite und die **Läufe**-Seite gibt es nicht mehr. Die Lauf-Historie steht in der Agentenliste, auf der Chat-Canvas und bei Genie AI, die dieselben Läufe liest, wenn du fragst.

**Auf der Chat-Canvas.** Ein Agent neben dem Chat liest sich in drei Abschnitten von oben nach unten:

- **Ergebnis** — der gezeigte Lauf, einmal benannt (*Lauf von 14:02 · Von Hand*). Eine Antwort zeigt ihre Überschrift, ihren Umfang und ihre ersten Zeilen; ein Rohwert oder ein Fehler steht in einer Zeile mit einem Kopier-Button, der alles kopiert; ein Lauf ohne Rückgabe sagt das. **Ganz anzeigen** öffnet den Lauf auf der Canvas des Agenten.
- **Verlauf** — die letzten Läufe als Reihe von bis zu zehn Balken, der älteste links. Farbe und Höhe jedes Balkens sagen, wie sein Lauf ging; tippe einen an, um ihn auf die Karte zu holen, und **Neuesten zeigen** führt zurück.
- **Ablauf** — was den Agenten startet (*Alle 10 Minuten*), dann jeder Schritt mit dem Symbol seiner Art und einem Abzeichen dafür, wie er lief: ein Haken, ein Kreuz, ein atmender Ring, während er läuft, gedimmt, wenn er nie erreicht wurde. Wo ein kurzer Wert passt, steht er neben dem Namen des Schritts (*#1040*, *2 Einträge*). Schleifen zeigen *Durchgang 3 von 12*. Die Schritte sind ein Bild, keine Buttons — **Agent öffnen** im Kopf der Karte hat den Rest.

Der [Prozess](/de/workspaces/overview#wissensmodell) einer Entität wird mit derselben Linie gezeichnet.

**Wer einen Lauf lesen kann.** Einen Lauf, den jemand von Hand gestartet hat, können diese Person, der Owner des Agenten und Personen mit Vollzugriff vollständig lesen; andere, die den Agenten sehen dürfen, sehen eine gesperrte Zeile mit Starter, Zeitpunkt und Status sowie *Das Ergebnis dieses Laufs ist nicht mit dir geteilt*. Läufe, die ein Zeitplan, Webhook, Kanal oder Phasenwechsel startet, folgen der Einstellung **Wer automatische Läufe liest**: alle, die den Agenten sehen dürfen (Standard), oder nur Owner und Vollzugriff. Personen mit Vollzugriff ändern sie; Genie AI kann sie nur einschränken. Läufe von vor dieser Einstellung bleiben geteilt wie bisher.

**Agenten, die als ein Mitglied laufen.** Startet jemand anderes einen solchen Agenten von Hand, nutzt er weiter die Integrationen und Credits dieses Mitglieds, liest Wissen, Wissensmodell und Tabellen aber als die Person, die ihn gestartet hat.

Ein Benachrichtigen-Schritt verlinkt standardmäßig auf den Lauf auf der Canvas seines Agenten — wähle in den Einstellungen des Schritts **eine Seite in Genie**, um woanders hinzuzeigen.

## Einen Agenten verwalten

Die Seite **Genie Agents** listet jeden Agenten in deinem Workspace auf — als Karten oder als Tabelle, je nachdem, wie du lieber durchsiehst (wechsle über den Ansicht-Umschalter; deine Wahl wird gemerkt). Das Einstellungsmenü (**⋯**) jedes Agenten — auf seiner Karte, seiner Zeile und in der Editor-Werkzeugleiste — bietet:

- **Umbenennen** — ändert seinen Anzeigenamen. Das ändert nie seinen zugrundeliegenden Bezeichner, sodass jedes darauf aufbauende veröffentlichte Tool oder jede Webhook-URL weiter funktioniert.
- **Pausieren / Fortsetzen** — Pausieren verhindert, dass er einen neuen Lauf startet (per Zeitplan, Webhook oder Aufruf durch einen anderen Agenten), bis du ihn fortsetzt; ein bereits laufender Lauf wird dadurch nie unterbrochen.
- **Teilen** — standardmäßig privat für die erstellende Person; sie kann ihn mit dem ganzen Workspace oder mit bestimmten Personen teilen, dieselben drei Zustände wie bei einem [Workspace-Chat](/de/workspaces/overview#workspace-chats-sind-standardmäßig-privat). Ein Mitglied, mit dem er geteilt wurde, kann ihn genauso öffnen, bearbeiten und löschen wie die besitzende Person — nur sie kann ändern, mit wem er geteilt ist.
- **Letzte Läufe** — sieh dir seine Lauf-Historie an, was bei jedem Lauf passiert ist, und öffne jeden Lauf auf der Canvas des Agenten — siehe [Lauf-Ergebnisse](#lauf-ergebnisse).
- **Benachrichtige mich** — folge dem Agenten, um die Benachrichtigungen zu bekommen, die sein Autor mit Followern teilt. Siehe [Benachrichtigungen eines Agenten erhalten](#benachrichtigungen-eines-agenten-erhalten).
- **Löschen** — entfernt den Agenten dauerhaft, jede Version davon und seine gesamte Lauf-Historie. Das lässt sich nicht rückgängig machen — pausiere ihn stattdessen, wenn er nur aufhören soll zu laufen.

### Benachrichtigungen eines Agenten erhalten

Du brauchst keine Bearbeitungsrechte am Agenten einer anderen Person, um von ihm zu hören. Wer einen Agenten ansehen kann, kann in seinen Einstellungen unter **Benachrichtigungen** **Benachrichtige mich** einschalten oder Genie AI bitten, ihm für dich zu folgen.

- **Der Autor entscheidet, was geteilt wird.** Nur Benachrichtigungsschritte, die auf **Eigentümer und Follower** stehen, erreichen Follower — gedacht für Neuigkeiten für ein Team, etwa *„Der nächtliche Import ist fehlgeschlagen"*, nicht für die Daten einer einzelnen Person. Schritte für die Person, die den Agenten ausgeführt hat, oder für den Eigentümer erreichen dich nie.
- **Du entscheidest, ob du es hörst.** Niemand kann dich zum Follower machen: Nur du kannst es einschalten, und nur du kannst es ausschalten.
- **Du erfährst nur, was du öffnen könntest.** Jeder Lauf prüft jeden Follower: Könntest du die Ergebnisse dieses Laufs nicht öffnen, wirst du nicht benachrichtigt. Verlierst du den Zugriff auf den Agenten, verstummt dein Folgen, ohne dass es jemand entfernt.

Follower werden per Push und E-Mail benachrichtigt, nach den eigenen Benachrichtigungseinstellungen jeder Person. Ein Agent kann eine begrenzte Zahl von Followern haben; ist sie erreicht, sagt **Benachrichtige mich** das.

## Auslöser

Ein Agent läuft nicht nur, wenn du ihn im Chat dazu aufforderst. Du kannst ihn so einrichten, dass er von selbst startet:

- **Nach Zeitplan** — dieselbe Idee wie bei [geplanten Jobs](/de/cloud/scheduling): „Führe das jede Nacht um 2 Uhr aus."
- **Über einen eingehenden Webhook** — gib einem externen Dienst (z. B. einem Formular-Tool oder Zahlungsanbieter) eine URL, die er aufrufen kann, und der Agent läuft, sobald eine Anfrage eintrifft.
- **Manuell** — führe ihn selbst aus, oder lass Genie AI ihn bei Bedarf ausführen.

Ein Agent kann mehrere Auslöser gleichzeitig haben — zum Beispiel nächtlich *und* über einen Webhook erreichbar.

<Tip>
  Bitte Genie AI zum Beispiel: „Führe das jeden Montag um 9 Uhr aus" oder „Gib mir eine Webhook-URL, die diesen Agenten auslöst" — dasselbe Gespräch, das ihn baut, richtet auch ein, wie er startet.
</Tip>

### Webhooks von Diensten, die ihre Anfragen signieren

Ein Webhook-Auslöser prüft jede eingehende Anfrage gegen genau ein Geheimnis. Es gibt zwei Arten:

| Geheimnis | Wer es erzeugt | Wie sich eine Anfrage ausweist |
| --- | --- | --- |
| **Genie-Token** | Genie erzeugt es und zeigt es einmal | Der Absender schickt es im Header `Authorization: Bearer …` oder `X-Workflow-Token` |
| **Signaturschlüssel des Absenders** | Der Dienst, der den Webhook sendet | Der Dienst signiert jede Zustellung; Genie prüft die Signatur |

Nutze den Signaturschlüssel für Dienste, die keinen frei wählbaren Header senden können und ihre Zustellungen selbst signieren — Resend, Clerk und alles andere, das auf Svix aufbaut oder der Spezifikation [Standard Webhooks](https://www.standardwebhooks.com/) folgt. So richtest du ihn ein:

<Steps>
  <Step title="Auslöser anfragen">
    Bitte Genie AI um einen Webhook-Auslöser und nenne den Dienst, zum Beispiel „Gib diesem Agenten einen Webhook für Resend". Genie AI zeigt eine Karte, die beide Geheimnisse anbietet.
  </Step>
  <Step title="Schlüssel in die Karte einfügen">
    Kopiere den Signaturschlüssel (`whsec_…`) aus dem Dashboard des Dienstes und füge ihn in die Karte ein — nie in den Chat. Genie speichert ihn verschlüsselt und zeigt ihn nie wieder an.
  </Step>
  <Step title="URL beim Dienst eintragen">
    Die Karte zeigt die URL, die du beim Dienst als Webhook-Endpunkt einträgst.
  </Step>
</Steps>

Ein Auslöser hält immer nur ein Geheimnis: Das eine zu setzen ersetzt das andere, und das Rotieren funktioniert genauso. Eine signierte Zustellung muss aktuell sein — höchstens fünf Minuten alt —, und eine Zustellung, die der Dienst nach einem Timeout erneut sendet, startet den Agenten nur einmal. Ein Token im Query-String der URL wird nicht akzeptiert.

### Einen Agenten aus dem Wissensmodell starten

Ein Agent kann auch starten, wenn sich in deinem [Wissensmodell](/de/workspaces/overview#wissensmodell) etwas bewegt: wenn eine Entität im Prozess einer Klasse die Phase wechselt. Wähle im Start-Panel **Bei einem Phasenwechsel**, dann eine Klasse, und beobachte jeden Übergang, einen bestimmten Übergang oder einen Verbleib von einer Anzahl Tagen in einer Phase. Jeder Lauf bekommt den Datensatz, der sich bewegt hat, sodass seine Schritte ihn nutzen können — etwa um eine E-Mail zu einem Vertrag zu entwerfen, der gerade *Unterzeichnet* erreicht hat. Du kannst ändern, was ein Auslöser beobachtet, direkt am Auslöser, und Genie AI bitten, ihn einzurichten. Klicke in der Prozessansicht bei einem Übergang auf **Genie Agent erstellen**, um einen Agenten zu bauen, der bereits mit diesem Übergang startet.

Auslöser direkt auf der Arbeitsfläche bearbeiten

Die **Start**-Karte des Editors nennt jeden echten Weg, wie der Agent startet — seinen Zeitplan als Klartext-Satz („Täglich um 02:00 Uhr", „Wenn etwas anruft" oder „Kein Zeitplan — dieser Agent läuft nur, wenn du auf Play drückst") sowie den nächsten Auslösezeitpunkt. Wähle sie aus, um das **Start**-Panel zu öffnen, in dem du einen Auslöser hinzufügen, einen bestehenden umplanen oder abschalten oder entfernen kannst — ganz ohne die Änderung Genie AI beschreiben zu müssen, auch wenn das weiterhin geht. Ein Zeitplan wird komplett aus einer Kadenz, einer Uhrzeit und Wochentag-Schaltern zusammengesetzt statt als Cron-Ausdruck eingetippt; alles, was sich mit den Reglern nicht abbilden lässt, öffnet unter **Erweitert** auf seinem rohen Zeitplan, statt still umgeschrieben zu werden.

<Note>
Sind alle Auslöser aus (oder keiner gesetzt) und ruft nichts anderes diesen Agenten auf, zeigt die Start-Karte ihn als unverbunden an — der Agent lässt sich weiterhin über die Seite, über Genie AI oder von einem anderen Agenten ausführen, aber nichts startet ihn von selbst.
</Note>

## Geheimnisse bleiben aus dem Ablauf heraus

Wenn ein Schritt einen API-Schlüssel oder ein anderes Zugangsdatum braucht — etwa einen `Authorization`-Header für einen Webhook —, wird es sicher als [Workspace-Secret](/de/workspaces/secrets) gespeichert — für den ganzen Workspace oder nur für diesen Agenten —, und der Schritt verweist nur namentlich darauf. Das Zugangsdatum selbst wird nie im Klartext in den Ablauf eingefügt oder dir (oder der KI) angezeigt.

## Abrechnung

Ein KI-Schritt verbraucht Credits genauso wie eine Nachricht im Chat. Schritte, die keine KI aufrufen — eine Datenbankabfrage, eine HTTP-Anfrage — verbrauchen keine KI-Credits.

## Grenzen

- Bis zu **25 Schritte** pro Agent.
- Ein Schleife-Schritt läuft eine begrenzte Anzahl von Durchläufen, und ein Lauf hat eine begrenzte Gesamtzahl an Schritten, sodass eine Schleife immer fertig wird, statt außer Kontrolle zu geraten.
- Ein geplanter Agent wird mindestens alle 10 Minuten auf seinen nächsten Lauf geprüft — ein feinerer Zeitplan als das ist daher nicht sinnvoll, Genie akzeptiert keinen solchen.
- Agenten können Agenten aufrufen, die wiederum Agenten aufrufen, bis zu 5 Ebenen tief. Ein Agent kann nie in seinem eigenen Aufruf landen, weder direkt noch über andere — Genie speichert eine solche Schleife nicht, und die Agentenauswahl graut Agenten aus, die diesen bereits aufrufen.
