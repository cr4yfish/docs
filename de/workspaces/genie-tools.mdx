Neben Genie Apps und Genie Agents kann ein Workspace auch **Genie Tools** enthalten — kleine interne Apps mit eigener Oberfläche, die du aber nicht baust oder bereitstellst. Du beschreibst Genie AI, was du möchtest („eine Tabelle mit Bestellungen und ein Formular, um eine hinzuzufügen"), und Genie zeigt es dir live an — direkt im Chat und auf einer eigenen Seite in deinem Workspace.

<Note>
Öffne **Projekte** in der Workspace-Seitenleiste und wähle im Art-Menü **Tools**, um alle Genie Tools im Workspace zu sehen, oder öffne eines direkt über seine eigene Seite unter `/workspace/<dein-workspace>/tools`.
</Note>

## Der Unterschied zu einer App oder einem Agent

| | Genie App | Genie Agent | Genie Tool |
|---|---|---|---|
| Was es ist | Generierter, bereitgestellter Code | Eine Abfolge von Schritten, dauerhaft ausgeführt | Eine Beschreibung, live angezeigt |
| Läuft, wenn | jemand sie besucht | ein Trigger auslöst oder du ihn ausführst | jemand es öffnet oder etwas darin anklickt |
| Hat eine Oberfläche | Ja, eine eigene | Nein — siehe [Genie Agents](/de/workspaces/workflow-apps) | Ja, gezeichnet aus Genies eigenen Komponenten |
| Wo die Daten liegen | In seiner eigenen Genie-Cloud-Datenbank | Wo auch immer es liest oder schreibt | In den eigenen Tabellen deines Workspace — kein Genie-Cloud-Projekt nötig |

Kurz gesagt: Ein **Agent** läuft von allein und hat keine Oberfläche; ein **Tool** hat eine Oberfläche und läuft nur, wenn jemand es öffnet. Beide können genau dieselben Daten lesen und schreiben — ein Genie Agent kann nachts neue Zeilen in eine Workspace-Tabelle schreiben, und ein Genie Tool kann sie am nächsten Morgen anzeigen, ohne dass dafür irgendetwas zwischen beiden verdrahtet werden muss.

## Ein Tool bauen

Es gibt keinen separaten formularbasierten Baukasten — Genie AI ist der Weg, ein Genie Tool zu erstellen und zu ändern, im selben Gespräch, das du auch für alles andere in Genie nutzt:

- „Baue mir ein Tool mit einer Tabelle für Bestellungen und einem Formular, um eine hinzuzufügen"
- „Füge einen Button hinzu, der die ausgewählte Bestellung als versendet markiert"
- „Zeige oben auf der Seite eine laufende Gesamtsumme der Bestellungen"

Genie AI zeigt das Tool schon während des Bauens direkt im Chat in Aktion — eine live funktionierende Tabelle, ein funktionierendes Formular — nicht nur eine Beschreibung dessen, was gemacht wurde. Sobald du zufrieden bist, wird es gespeichert und erscheint auf der **Tools**-Seite — privat für dich, bis du es teilst, genau wie bei einem [Genie Agent](/de/workspaces/workflow-apps#einen-agenten-verwalten): öffne sein Einstellungsmenü (**⋯**) und wähle **Alle im Workspace** oder **Nur ausgewählte Personen**. Ein Button **Genie AI fragen** auf der eigenen Seite des Tools öffnet genau das Gespräch wieder, in dem du es gebaut oder zuletzt bearbeitet hast, statt bei null anzufangen.

<Tip>
Weil es keinen separaten Editor gibt, ist das Ändern eines Tools immer ein Gespräch: „füge eine Spalte für die Telefonnummer des Kunden hinzu" oder „entferne den Löschen-Button, ich möchte nicht, dass jemand aus Versehen Bestellungen löscht."
</Tip>

## Was ein Genie Tool anzeigen kann

Die Seite eines Tools setzt sich aus einer kleinen Auswahl an Bausteinen zusammen, die Genie AI für dich auswählt und anordnet:

| Baustein | Zeigt |
|---|---|
| Text | Ein oder zwei Zeilen geschriebenen Inhalts |
| Kennzahl | Eine einzelne Zahl oder einen Wert mit Beschriftung |
| Summary | Bis zu sechs KPI-Karten über einer Tabelle auf einen Blick |
| Diagramm | Ein Balken-, Linien-, Kreis-, Donut-, Rosen- oder Streudiagramm, gezeichnet aus einer Tabelle oder den Daten eines anderen Bausteins |
| KPI | Eine Zahl mit Trendlinie und einem Vergleich gegen ein anderes Segment |
| Vergleich | Zwei oder mehr Segmente deiner Daten nebeneinander, mit hervorgehobenen Unterschieden |
| Anomalien | Ausreißer, leere Felder und doppelte Zeilen, automatisch in einer Tabelle gefunden |
| Insights | Eine von der KI verfasste Zusammenfassung dessen, was in einer Tabelle auffällt |
| Tabelle | Datenzeilen, mit den Spalten, die du möchtest |
| Liste | Die Zeilen eines Knotens als Einträge — als einfache Liste, Kachel- oder Karten-Ansicht, Zeitleiste oder Posteingang-Ansicht |
| Details | Alle Felder eines ausgewählten Datensatzes, mit Buttons, die darauf wirken (aktualisieren, löschen, was du beschreibst) |
| Kalender, Kanban, Organigramm, Karte | Die Zeilen einer Tabelle als Monatskalender, Drag-and-Drop-Board, eingerücktes Organigramm oder Punkte auf einer Karte |
| Übergänge | Wo eine Entität in ihrem [Prozess](/de/workspaces/overview#wissensmodell) steht, mit einer Schaltfläche für jeden Schritt, den sie jetzt machen kann — der Schritt wird mit dir als ausführender Person festgehalten |
| Kommentare | Verschachtelte Notizen zu dem Datensatz, der anderswo auf der Seite ausgewählt ist |
| Spalten, Tabs | Fasst andere Bausteine nebeneinander oder hinter Reitern zusammen, für eine umfangreichere Seite |
| Kopfzeile, Hero, CTA, Feature(s), Partner, Beiträge, Preise, Links | Statische Landingpage-Abschnitte — für ein Tool, das auch als kleine Marketing-Seite dient |
| Custom Code | Sandboxed HTML, CSS und JavaScript, das Genie AI für eine Ansicht schreibt, die kein anderer Baustein abdeckt |
| Import | Lade eine oder mehrere Tabellenkalkulationen — von deinem Gerät oder direkt aus deiner [Wissensdatenbank](/de/workspaces/overview#wissensdatenbank) — in eine Workspace-Tabelle hoch. Spalten werden automatisch zugeordnet, Genie AI springt nur bei einer Überschrift ein, die sie nicht selbst zuordnen kann |
| Dateien | Die bereits in eine Tabelle importierten Dateien, einzeln oder alle zusammen entfernbar |
| Export | Eine ganze Tabelle als CSV, Excel oder PDF herunterladen |
| Rohdaten | Ein beliebiges Ergebnis, lesbar formatiert |
| Formular | Felder, die beim Absenden eine Aktion auslösen — eine Zeile hinzufügen, eine aktualisieren, was auch immer du beschreibst. Ein Feld kann auch ein Datei-Upload beliebigen Typs sein, nur für diese eine Übermittlung aufbewahrt oder direkt in deiner [Wissensdatenbank](/de/workspaces/overview#wissensdatenbank) abgelegt — direkt abgelegt, oder aus einem Knowledge-Ordner ausgewählt |
| Button | Löst eine Aktion ohne Eingabe aus — etwas als erledigt markieren, eine Zusammenfassung verschicken |

Jeder Baustein behandelt seine Zwischenzustände selbst: Eine Tabelle zeigt beim Laden ein Platzhalter-Skelett, sagt klar, wenn sie leer ist, und wenn etwas fehlschlägt, wird der Rest der Seite trotzdem angezeigt — mit dem Fehler direkt neben dem, was kaputt war. Ein defekter Baustein macht nie das ganze Tool leer.

Ein **Tabellen**-Baustein ist durchsuchbar und sortierbar, mit fixierten Kopfzeilen, damit eine lange Liste lesbar bleibt — und wo das Tool es aktiviert, lässt eine Checkbox-Spalte Zeilen auswählen, um sie gemeinsam zu bearbeiten, etwa nur die ausgewählten zu exportieren. Eine Zelle mit einem einzelnen Link wird als anklickbares Vorschaubild für ein Bild, als benannter Download-Link für eine Datei oder als einfacher Link für alles andere angezeigt — statt als reiner Text.

Ein **JSON**-Baustein liest einen Wert, statt ihn auszukippen: die Felder eines Objekts als Paare aus Bezeichnung und Wert, verschachtelte Werte unter ihrem Schlüssel und eine Liste von Objekten als Karten mit Titel. **Rohes JSON anzeigen** wechselt zu genau dem, was zurückkam.

Eine **Tabelle** kann auch eine ganze Klasse deines [Wissensmodells](/de/workspaces/overview#wissensmodell) zeigen — etwa jeden Vertrag, den Genie in deinen Dokumenten gefunden hat — als seitenweises Raster, sortiert nach Name oder Erstellungszeitpunkt. Sie zeigt die Gesamtanzahl (oder „5.000+“, sobald sie über die gezählte Grenze hinausgeht), sperrt eine Zeile, deren Quelldokumente du nicht alle lesen darfst, und verlinkt jede Entität auf ihre vollständige Karte. Der **Export** lädt die ganze Klasse herunter — außer bei einer Klasse, die zu groß zum Zählen ist: Dort wird der Export abgelehnt, statt abgeschnitten zu werden. Ein Klassen-Raster hat kein Suchfeld und keine Filter.

**Das zweite Öffnen einer Seite geht schneller.** Stellt das Laden einer Seite dem Modell von Genie AI dieselbe Frage zu denselben Daten, verwendet es seine frühere Antwort bis zu einen Tag lang wieder, statt neu zu fragen — eine Seite, die Berichte zusammenfasst, wartet also nicht bei jedem Öffnen auf dieselbe Antwort und berechnet sie dir nicht erneut. Ändern sich die gelesenen Daten, wird sofort neu gefragt, und **Aktualisieren**, **Erneut versuchen** oder eine Aktion fragen immer neu. Websuchen und Website-Downloads werden nie wiederverwendet.

Uploads — in einen **Import**-Baustein, ein Datei-Feld in einem **Formular**, oder aus deiner [Wissensdatenbank](/de/workspaces/overview#wissensdatenbank) ausgewählt — nehmen Dateien bis zu 200 MB entgegen. Große Dateien werden automatisch komprimiert, damit alles zügig bleibt; bitte Genie AI, diese Komprimierung für ein bestimmtes Datei-Feld stärker oder schwächer einzustellen, falls die Standardeinstellung nicht zu dem passt, was du hochlädst.

## Einen Datensatz auswählen

Ein Klick auf eine Zeile in **Liste**, **Tabelle**, **Kalender**, **Kanban**, **Organigramm** oder **Karte** wählt ihren Datensatz für den Rest der Seite aus: Ein **Details**-Baustein zeigt alle Felder dieses Datensatzes, ein **Kommentare**-Baustein zeigt seinen Thread, ein **Formular** kann ihm `follows` und ihn direkt bearbeiten oder darauf einwirken, und jeder Baustein kann nur angezeigt werden, solange der ausgewählte Datensatz etwas Bestimmtes erfüllt. Eine **Liste** kann außerdem mit einer anderen `linked` sein — sie zeigt dann nur die Zeilen, die zu dem gerade Ausgewählten gehören, etwa die eigenen Aufgaben eines Projekts unter dem Projekt, zu dem sie gehören.

Ein **Formular**, das einem ausgewählten Datensatz folgt, kann sich auch mit dessen aktuellen Werten **vorausfüllen** — zum Bearbeiten an Ort und Stelle statt nur zum Anlegen neuer Datensätze; nur die Felder, die du tatsächlich änderst, werden zurückgesendet, sodass ein Wert, den eine andere Aktion geändert hat, während das Formular offen war, nie mit einem veralteten Wert überschrieben wird.

## Formulare hinter einer Schaltfläche und Datensatz-Panels

Ein Formular muss nicht auf der Seite stehen. Eine **Tabelle**, **Liste**, ein **Kalender**, **Kanban**, **Organigramm** oder eine **Karte** kann ihre Formulare als Schaltflächen anbieten — ein **Hinzufügen** in der Kopfzeile oder als Erstes, was du siehst, wenn sie leer ist —, und das Formular öffnet sich in einem Dialog oder einem seitlichen Panel, je nachdem, was besser passt. So bleibt das Raster der Mittelpunkt der Seite. In einem **Kanban** startet eine aus einer Spalte hinzugefügte Karte in dieser Spalte, und in einem **Kalender** beginnt ein von einem Tag aus hinzugefügter Termin an diesem Tag.

Öffnest du eine Zeile, öffnet sich ihr Datensatz als **Panel**: Die Felder des Datensatzes, sein Bearbeitungsformular, seine Kommentare und alles andere auf der Seite, das sich auf den ausgewählten Datensatz bezieht, sind dort gebündelt, statt in Karten unter dem Raster auf eine Auswahl zu warten. Das Absenden eines Formulars im Panel schließt es und bestätigt mit einer kurzen Meldung. Jede **Tabelle** hat ein Panel, sodass sich eine Zeile, deren Zellen einen langen Wert abschneiden, immer vollständig lesen lässt.

Eine Seite, die deine [Wissensdatenbank](/de/workspaces/overview#wissensdatenbank) liest, führt Schritte, die schreiben oder senden, nur über deren eigene Schaltfläche aus — das Öffnen oder Blättern der Seite löst nie einen aus.

## Ein Tool aus einer Klasse deines Wissens

Eine Klasse des [Wissensmodells](/de/workspaces/overview#wissensmodell) kann zum Tool werden, ohne dass es jemand beschreibt. Wähle **Als Tool öffnen** bei einer Klasse im Klassen-Panel der Ontologie, und Genie baut eine Listenseite — ein Raster der Entitäten der Klasse mit Seitenaufteilung — plus eine Datensatzseite für jede davon: ihre Karte, ihren Prozess, wenn die Klasse einen hat, und ein Bearbeitungsformular. Oder wähle **Mit Genie AI bauen** und bitte Genie AI, es weiter zu formen. Ein Formular auf so einer Seite kann seine Felder automatisch erfragen: ein Feld pro Eigenschaft der Klasse, so typisiert, wie die Klasse es definiert — eine später hinzugefügte Eigenschaft ist beim nächsten Laden im Formular. Alles läuft als du — was du im Wissensmodell nicht lesen oder bearbeiten kannst, kann das Tool auch nicht.

Führt Genie AI eine Aktion eines Tools aus dem Chat aus, erscheint das Ergebnis als Karte mit der Aktion, dem Tool, den gesendeten Werten und der Antwort des Tools, samt Link zur Seite. Ein Tool kann außerdem einen **Import**-Block haben, der ein Tabellenblatt (Excel, Numbers, CSV oder TSV) in eine Klasse deines Wissens einliest: Du wählst die Datei, ordnest ihre Spalten den Eigenschaften der Klasse zu, und Genie legt pro Zeile eine Entität an oder aktualisiert sie.

## Den Ablauf einer Seite gestalten

Ein Formularfeld kann **bedingt** sein — nur gefragt, wenn eine frühere Antwort passt, sodass ein Formular verzweigen kann, ohne für jeden Pfad eine eigene Seite zu brauchen — oder **versteckt**, wobei es einen festen oder aus Vorlagen erzeugten Wert sendet, ohne überhaupt eine Frage zu stellen. Ein Feld kann außerdem mit einem **Standardwert** starten, und ein Auswahl- oder Mehrfachauswahlfeld kann seine Optionen direkt aus den Zeilen eines anderen Bausteins lesen, statt sie fest einzutippen.

Fasse Bausteine mit **Spalten** (2–4 nebeneinander) oder **Tabs** zusammen, um eine umfangreiche Seite zu ordnen, und füge **statische Bausteine** hinzu — eine Kopfzeile, einen Hero-Bereich, eine Handlungsaufforderung, eine Feature-Liste, Partner-Logos, eine Preistabelle oder Link-Karten — für ein Tool, das gleichzeitig als kleine Landingpage dient. Ein **Custom-Code**-Baustein lässt Genie AI Sandboxed HTML, CSS und JavaScript für die seltene Ansicht schreiben, die keiner der obigen Bausteine abdeckt; er läuft isoliert vom Rest der Seite und kann weder auf deine Daten noch auf das Netzwerk zugreifen, außer worauf er ausdrücklich Zugriff bekommen hat.

Ein Raster über eine der Tabellen deines Workspace bekommt eine Spalte **Erwähnungen**, sobald seine Zeilen Freitext enthalten. Jeder Chip ist eine Person, ein Projekt oder eine Firma, die die Wörter der Zeile benennen; öffne ihn, um die Entität zu sehen, oder drücke **Nicht diese**, um eine falsche Verknüpfung von der Zeile zu lösen. Siehe [Wissensmodell](/workspaces/overview#wissensmodell).

## Seiten, und ein Formular, das eins nach dem anderen fragt

Ein Tool mit viel Inhalt ist keine einzige lange Scroll-Seite: Eine Seite, die sowohl lang ist als auch verschiedene Aufgaben mischt — Daten importieren, verwalten, ein Diagramm lesen —, wird automatisch in fokussierte Seiten aufgeteilt, typischerweise **Dashboard**, **Import**, **Verwalten** und **Analyse**, jede nur mit den Bausteinen, die sie braucht. Die gerade geöffnete Seite steht in der URL des Tools, sodass ein Link auf eine bestimmte Seite zeigen kann, und ein Tool behält bis zu 10 Seiten (siehe [Limits](#limits)).

Eine Seite kann auch als **Formular** laufen: Statt eines langen Formular-Bausteins wird sie Frage für Frage mit einer Fortschrittsanzeige gezeichnet und endet nach dem Absenden auf einem Dankeschön-Bildschirm — dieselbe Form wie ein Typeform.

## Wo die Daten liegen

Die Daten eines Genie Tools liegen in den eigenen Tabellen deines Workspace — einem schemalosen Ort für Datensätze, für den weder eine Genie App noch eine Genie-Cloud-Datenbank nötig ist. Bittest du Genie AI um „ein Tool mit einer Tabelle für Leads", legt sie die Tabelle beim ersten Schreibvorgang an; es gibt kein Schema, das du vorab entwerfen musst, und ein neues Feld später hinzuzufügen ist genauso einfach ein Gespräch wie die Anfrage nach dem Tool selbst.

Dieselben Workspace-Tabellen stehen auch als Schritt innerhalb eines [Genie Agent](/de/workspaces/workflow-apps) zur Verfügung — ein Agent kann also nachts Leads sammeln und einfügen, und ein Genie Tool kann sie am nächsten Morgen auflisten, beide lesen und schreiben genau dieselben Zeilen.

Eine Tabelle kann außerdem **auf die Zeilen einer anderen Tabelle verweisen** — etwa eine Aufgabe auf ihr Projekt. Bitte Genie AI, sie zu verknüpfen, und sie hält die Verknüpfung stimmig: Eine Aufgabe kann nur auf ein existierendes Projekt zeigen, ein Projekt mit noch verknüpften Aufgaben lässt sich nicht versehentlich löschen (oder, wenn du es lieber so willst, löscht das Löschen nur die Verknüpfungen), und Blöcke können den Namen des verknüpften Projekts direkt in der Zeile der Aufgabe zeigen und danach sortieren oder filtern.

Auch große Tools bleiben schnell änderbar: Genie AI bearbeitet nur die Seiten und Blöcke, um die du gebeten hast, statt das ganze Tool neu zu schreiben, und lehnt eine Änderung ab, die eine zwischenzeitlich von jemand anderem gespeicherte Änderung überschreiben würde.

<Note>
Ein Genie Tool läuft immer mit **deinem eigenen** Zugriff — es zu öffnen, oder es von jemand anderem öffnen zu lassen, gibt niemals fremde Daten oder Zugangsdaten preis. Liest ein Tool aus einer deiner verbundenen Integrationen, geschieht das mit deiner eigenen Verbindung — genauso, als hättest du Genie AI direkt danach gefragt.
</Note>

## Limits

| Limit | Wert |
|---|---|
| Seiten pro Tool | 10 |
| Bausteine pro Seite | 30 |
| Felder pro Formular | 20 |
| Spalten pro Tabellen-Baustein | 30 |
| Gelesene Zeilen pro Abfrage | 200 |
| Geänderte Zeilen pro Schreibvorgang | 100 |
| Workspace-Tabellen pro Workspace | 100 |
| Zeilen pro Workspace-Tabelle | 500.000 |

<Tip>
Bitte Genie AI zum Beispiel um „liste unsere Genie Tools auf" oder „füge der Leads-Tabelle eine Zeile hinzu" — sie kann Tools und ihre zugrunde liegenden Tabellen in deinem Auftrag lesen, bauen, ausführen und bearbeiten, genau wie du es auf der Tools-Seite selbst könntest.
</Tip>
