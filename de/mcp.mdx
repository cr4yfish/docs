title: "Genie MCP-Server"
description: "Verbinde Claude Desktop, Cursor oder jeden anderen MCP-kompatiblen KI-Client mit deinem Genie-Workspace. Projekte erstellen, Prompts senden und deinen Workspace programmatisch verwalten."
---

Genie stellt einen MCP-Server (Model Context Protocol) bereit, sodass jeder kompatible KI-Client — Claude Desktop, Cursor, eigene Agenten — Workspaces und Projekte programmatisch verwalten kann. Erstelle Apps, sende Folge-Prompts, prüfe den Build-Status, verwalte Teammitglieder und führe Workspace-Chats direkt in deinem KI-Assistenten durch.

## Endpunkt

```
https://www.genie-app.de/api/mcp
```

Der Server verwendet das **Streamable-HTTP-Transport**. Sitzungen sind zustandslos — keine dauerhafte Verbindung erforderlich.

## Authentifizierung

Der MCP-Server verwendet **OAuth 2.0 mit PKCE**, beschränkt auf einen Genie-Workspace. Nach dem browserbasierten OAuth-Flow trägt jede Anfrage ein kurzlebiges JWT als `Bearer`-Token.

Die meisten MCP-Clients (Claude Desktop, Cursor) führen den OAuth-Flow automatisch durch, wenn du den Server-Endpunkt hinzufügst.

## Schnellstart

1. Füge `https://www.genie-app.de/api/mcp` als MCP-Server in deinem KI-Client hinzu.
2. Schließe die OAuth-Autorisierung im Browser ab, wenn du dazu aufgefordert wirst.
3. Starte direkt: *"Erstelle ein Projekt: einen Inventar-Tracker mit Import und Export."*

## Beispiele

### Projekt erstellen

```json
{
  "tool": "create_project",
  "arguments": {
    "prompt": "Erstelle ein SaaS-Dashboard mit Dark Mode, Benutzeranmeldung und einer Abrechnungsseite"
  }
}
```

Gibt den Projekt-Slug, die Deployment-URL und einen Link zurück, um den Live-Build zu verfolgen.

### Folge-Prompt senden

```json
{
  "tool": "send_followup_prompt",
  "arguments": {
    "project_slug": "mein-saas-dashboard-abc123",
    "prompt": "Füge eine Einstellungsseite mit Profilfoto-Upload hinzu"
  }
}
```

Gibt sofort `"ok"` zurück — der Build läuft im Hintergrund. Mit `get_project_status` den Status prüfen.

### Build-Fortschritt prüfen

```json
{
  "tool": "get_project_deployment_status",
  "arguments": { "project_slug": "mein-saas-dashboard-abc123" }
}
```

Gibt die aktuelle Phase zurück: `submitted`, `optimizing`, `coding`, `deploying`, `finished` oder `error`.

## Workspace-Chat vs. Projekt-Prompts

| | `send_workspace_chat` | `create_workspace_chat` | `send_followup_prompt` |
|---|---|---|---|
| **Bereich** | Ganzer Workspace | Ganzer Workspace | Einzelnes Projekt |
| **Im Verlauf gespeichert** | Nein | Ja | Ja |
| **Mehrteilig** | Nein | Ja — `conversation_id` übergeben | Nein |
| **Erstellt Code** | Nein | Nein | Ja |
| **Am besten für** | Schnelle Fragen | Recherche-Threads | Features hinzufügen |

## Zugriffskontrolle

- **Alle Mitglieder** können Workspace- und Projektinformationen, das Credit-Guthaben und den Workspace-Chat lesen.
- **Owner und Admins** können schreiben: Einstellungen aktualisieren, Mitglieder einladen, Integrationen verwalten und PII-Regeln anpassen.
- **Workspace-weiter Credit-Verbrauch** (`scope: 'workspace'`) und das **PII-Erkennungsprotokoll** erfordern Owner- oder Admin-Rechte.
