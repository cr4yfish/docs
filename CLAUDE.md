# Docs repo instructions

## Translations

- Every page exists in both English (`/`) and German (`de/`). **Whenever you add or change content on an English page, you must apply the same change to the corresponding German page in the same commit/PR.** Never leave a translation behind.
- German pages live under the `de/` directory and mirror the English structure exactly (e.g. `billing/credits.mdx` → `de/billing/credits.mdx`).
- Translate all user-facing text: headings, body copy, callout/tip/note/warning content, card labels, and alt text. Do not translate code blocks, file paths, or proper nouns (product names like "Genie", "Supabase", etc.).
- If a German page does not yet exist for a new English page you create, create it in the same PR.
